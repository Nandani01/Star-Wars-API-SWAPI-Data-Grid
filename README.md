# Star Wars Data Grid

A high-performance, dark-themed Angular application displaying Star Wars fleet data fetched from SWAPI with infinite scrolling, inline cell editing, and resizable grid columns.

---

## 1. Setup Instructions

### Prerequisites
* **Node.js**: `v18.x` or higher
* **npm**: `v9.x` or higher
* **Angular CLI**: `v19.x`

### Quick Start
```bash
# Clone the repository
git clone <repository-url>
cd star-wars-grid

# Install dependencies
npm install

# Start the local development server
ng serve
